C programs, translated to daslang, running as WebAssembly

Each demo is a real C program converted to daslang by c2das-re, then compiled ahead of time to wasm. The converted sources are in c2das-ports.

  • PureDOOM: play Freedoom, or run the demo1 timedemo and compare every tic's checksum with the native build.

A modern desktop browser is needed (WebAssembly threads and exceptions). The first visit reloads once to enable cross-origin isolation.
