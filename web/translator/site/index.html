C to daslang, in your browser

c2das-re translates C into readable daslang. Here its translator runs as WebAssembly: each example's C is read by clang into c2das-re's C-IR when the page is built, and everything after that — the emitter, the layout law, the readability forms, the knobs below — runs live in the page, compiled from c2das-re's own daslang to wasm64. Change a knob and the module is spelled again. The Lua console runs Lua 5.4, translated from C by c2das-re and compiled to wasm.
