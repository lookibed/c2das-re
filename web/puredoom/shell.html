PureDOOM, translated from C to daslang, compiled to WebAssembly

The C source of PureDOOM was converted to daslang by c2das-re (puredoom-readable, the processed variant), then compiled ahead of time to wasm by daslang's LLVM backend. Nothing here is the original C. Game data: Freedoom Phase 2 (BSD licence), the official 0.13.0 release, loaded at run time; never id Software's commercial WADs.
