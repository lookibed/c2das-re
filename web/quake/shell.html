Quake, translated from C to daslang, compiled to WebAssembly

quakegeneric (id Software's Quake engine behind a small platform layer) was converted to daslang by c2das-re (quakegeneric/readable), then compiled ahead of time to wasm by daslang's LLVM backend. Game data: the Quake 1.06 shareware pak0.pak, id Software's freely distributable episode, loaded at run time. No sound: the port's sound layer is a null one.
